# Как тестировать мод без передачи гигабайтов игры

Короткий ответ: **передавать сами файлы игры не нужно и не следует.**
Нужен отпечаток установки — сотня байт, а не 6 ГБ. Он отвечает на
единственный вопрос, который блокирует работу: «эта установка — ровно та,
под которую написан импортёр, или другая версия».

## Почему не выгрузка игры целиком

- **Права.** Файлы игры принадлежат правообладателю. Владелец установленной
  копии может ею пользоваться, но не распространять. Выгрузка на любой
  публичный хостинг — это распространение, даже если ссылка «только для
  теста».
- **Ненадёжность.** Google Drive отдаёт большие файлы через подтверждение:
  первая попытка возвращает HTML-страницу, а не байты. Автоматическая
  загрузка на этом ломается — ровно та проблема, из-за которой в лаунчере
  уже зафиксировано: `raw.githubusercontent.com` не работает, `codeload`
  работает.
- **Размер.** BFME2 — 4,96 ГБ, RotWK — 967 МБ. Песочница `/tmp` не
  переживает перезапуск, значит выгрузку пришлось бы повторять.

## Что передавать вместо файлов

Отпечаток: путь, размер и md5 каждого архива.

```bash
# на своём компьютере, из папки установки
python3 tools/retail_fingerprint.py "D:/Games/BFME2" --json bfme2-отпечаток.json
python3 tools/retail_fingerprint.py "D:/RotWK" --game rotwk --json rotwk-отпечаток.json
```

Инструмент сверяет каждый архив с политикой `contracts/*-archives.json`
и печатает вердикт. Отчёт `*.json` — это несколько килобайт: его можно
прислать в переписке, положить в репозиторий или приложить к задаче.

Быстрый вариант (размеры, без чтения содержимого) — `--sizes-only`:
мгновенно и уже отсекает чужую версию.

### Что показывает отпечаток

| Вердикт | Что значит |
|---|---|
| `СОВПАДАЕТ С ПОЛИТИКОЙ (107/107)` | установка ровно 1.06 EN, импортёр получит все данные |
| `отличается: N` | другая версия/локализация/патч — называем файлы и размеры |
| `отсутствует: N` | неполная копия (как `open-bfme`: нет 4 архивов на 1030 МБ) |
| `лишние .big` | моды или другой патч поверх игры |

Проверено на реальной неполной 2.01: 102 md5 сошлись за 1,1 секунды,
4 отсутствующих названы по именам и размерам.

## Как я проверяю то, что не требует данных

Большая часть работы **не требует файлов игры вовсе**, и это проверяется в
песочнице:

| Что | Чем проверяется | Нужны ли данные |
|---|---|---|
| Логика рандомайзера (сид, драфт, хаос, сохранения) | `game/tests/randomizer_*` — 8/8 | нет |
| Лобби, синхронизация, вёрстка | снимки Godot 4.7.2 + отчёт `GEOM` | нет |
| Лаунчер, прогресс, отказы | 137 тестов | нет |
| Чтение BIG, каталог, профили | импортёр строит архив на лету (`test_big.py`) | нет |
| **Значения из INI retail** | сравнение с эталоном из установки | **да** |
| **Конвертация W3D → glTF** | реальные модели | **да** |
| **Сборка карт и террейна** | реальные `terrain.big` + BFME2 | **да** |

Импортёр прямо это признаёт — `importer/tests/retail_inputs.py`:

> Oracle tests compare our conversion against bytes read from a retail install.
> That install is *never* part of this repository... When no install is found
> the helpers return a path that does not exist, which makes the `skipif`
> guards skip cleanly instead of failing. **That is the intended behaviour for
> contributors without the game.**

То есть 51 такой тест в самом upstream спроектирован пропускаться без игры.
